# Resolvendo o 8-Puzzle com A*

Este projeto consiste na implementação do problema clássico do 8-Puzzle utilizando a linguagem Python e o algoritmo de busca informada A* (A-Star).

O objetivo do programa é encontrar a sequência de movimentos necessária para transformar um estado inicial em um estado objetivo, utilizando duas heurísticas amplamente conhecidas em Inteligência Artificial:

* Distância de Manhattan
* Heurística de Hamming

Além da resolução do problema, o projeto também permite a comparação de desempenho entre essas duas heurísticas, analisando sua eficiência na busca pela solução ótima.

## Tecnologias utilizadas
* Python 3
* Conceitos aplicados
* Algoritmo de busca A*
* Busca heurística
* Inteligência Artificial
* Espaço de estados
* Função de avaliação f(n) = g(n) + h(n)
* Heurísticas admissíveis
 
## Objetivo acadêmico
Este projeto foi desenvolvido com fins de estudo e aplicação prática dos conceitos de busca heurística e resolução de problemas clássicos de Inteligência Artificial, especialmente no contexto do problema 8-Puzzle.
